# Source and dependency provenance

`scripts/UTILITIES_Wang.py`, `scripts/GSLIB_parfl_011.py` and `legacy/Workflow_U9_Wang.py` were supplied with the GRID D2.2 work. English release preparation translates Chinese comments in UTILITIES_Wang.py and the legacy workflow; executable tokens and author notices are unchanged. Original hashes are retained in `docs/core_original_hashes.json`, release hashes in `docs/core_hashes.json`, and token-equivalence records in `docs/core_source_localization.json`. GSLIB_parfl_011.py remains byte-identical. This reorganization does not assign a new license to those sources. The existing remote repository LICENSE (GNU Affero General Public License v3.0) is retained unchanged. Original third-party notices and data provenance remain applicable; no additional permission for third-party materials is inferred from their availability.

Python dependencies are listed in `requirements.txt` and retain their respective licenses. GSLIB90 executables are external runtime dependencies supplied through `GSLIB_DIR` or `--gslib-dir`; no executable is redistributed here.

The default example now includes a spatial subset of the user-supplied public Bavarian borehole archive. Original record values are preserved; source hashes, row mapping and the original quick guide accompany the subset. See data/real_munich/README.md. Historical fictional inputs are isolated in tests/fixtures/synthetic. The full borehole archive is not included. The supplied English D2.1 reference is included under docs/reports. Internal D2.2 review drafts and editorial correspondence are not part of this release. Sampled terrain elevations and a derived below-ground mask are included under data/article with the original terrain source hashes; the full terrain rasters are not included. No new license grant is inferred for the documents, source data, terrain derivatives or reproduced figures. These materials retain their existing notices and attribution.
